# Portofolio Web & Link Hub — Abdul Fattah

Website portofolio interaktif dengan fitur **Mode Link Hub** untuk menampilkan karya redesign link hub & website.

- 🌐 **Live Portofolio:** https://abdulfattah105-ne.github.io/portofolio-afbdltahh/
- 🔗 **Live Link Hub:** https://abdulfattah105-ne.github.io/portofolio-afbdltahh/#hub

## Fitur Utama
- **Dual Mode (Portofolio & Link Hub):** Beralih cepat lewat tombol navigasi, shortcut keyboard `H`, atau hash `#hub`.
- **Live Preview Modal:** Pratinjau proyek secara langsung dalam tampilan Mobile maupun Desktop.
- **Filter & Pencarian Tautan:** Filter kategori proyek serta pencarian instan di mode Link Hub.
- **Security-Hardened:** Dilengkapi Content Security Policy (CSP), isolasi `iframe sandbox`, proteksi *anti-clickjacking*, serta proteksi kontak *anti-bot scraper*.
